# Конспект занятий по Python

Здесь лежит один файл с конспектом и примерами: [konspekt.py](konspekt.py). Я буду дополнять его после занятий. Репозиторий открыт всем: чтобы посмотреть или скачать материалы, аккаунт GitHub не нужен.

## Зачем копировать репозиторий на компьютер

Так можно открыть конспект даже без интернета, запускать примеры у себя и экспериментировать со своей копией файла. Изменения в вашей папке не меняют мой конспект на GitHub.

## Способ 1. Скачать ZIP — самый простой

Подходит, если нужно один раз получить файлы и не хочется устанавливать дополнительные программы.

1. Откройте [страницу репозитория](https://github.com/ilandroxxy/python-lesson-notes).
2. Нажмите зелёную кнопку **Code** над списком файлов.
3. Выберите **Download ZIP**.
4. Найдите архив в папке «Загрузки» и распакуйте его: на Windows выберите «Извлечь всё», на macOS дважды нажмите на ZIP.
5. Откройте появившуюся папку. В ней будут README.md и konspekt.py.

ZIP — это снимок на момент скачивания. Когда я обновлю конспект, скачайте ZIP ещё раз.

## Способ 2. Клонировать через GitHub Desktop

Подходит, если вы хотите получать новые версии конспекта в той же папке. **Клонировать** значит создать на компьютере связанную с GitHub копию репозитория.

1. Установите [GitHub Desktop](https://desktop.github.com/) для Windows или macOS и войдите в свой аккаунт GitHub. Если аккаунта нет, можно воспользоваться способом с ZIP.
2. Откройте [страницу репозитория](https://github.com/ilandroxxy/python-lesson-notes).
3. Нажмите **Code** → **Open with GitHub Desktop**. Если браузер спросит разрешение открыть программу, подтвердите.
4. В окне GitHub Desktop выберите папку на компьютере, например «Документы», и нажмите **Clone**.
5. Откройте созданную папку python-lesson-notes: в ней находятся README.md и konspekt.py.

Когда появится новый материал, откройте этот репозиторий в GitHub Desktop, нажмите **Fetch origin**, затем, если появится кнопка **Pull origin**, нажмите её. Так новые записи попадут в вашу папку. Если вы сами изменяли konspekt.py, GitHub Desktop может попросить сначала сохранить ваши изменения или помочь разрешить конфликт.

## Если вы уже пользуетесь терминалом и Git

Перейдите в папку, где хотите хранить конспект, и выполните:

```bash
git clone https://github.com/ilandroxxy/python-lesson-notes.git
```

Чтобы позже получить обновления:

```bash
cd python-lesson-notes
git pull
```

## Как открыть и запустить конспект

Файл konspekt.py можно читать в любом текстовом редакторе, например в IDLE или PyCharm. Чтобы запустить примеры, нужен установленный Python 3. Откройте файл в своей среде программирования и нажмите «Запустить». В терминале можно выполнить `py konspekt.py` на Windows или `python3 konspekt.py` на macOS.

Если хотите сохранить свои упражнения, создайте рядом отдельный файл: тогда обновлять конспект будет проще. Не публикуйте в открытом репозитории фамилии, телефоны, пароли и другие личные данные.

Подробные справки GitHub: [скачивание ZIP](https://docs.github.com/en/repositories/working-with-files/using-files/downloading-source-code-archives), [клонирование в GitHub Desktop](https://docs.github.com/en/desktop/adding-and-cloning-repositories/cloning-a-repository-from-github-to-github-desktop), [получение обновлений](https://docs.github.com/en/desktop/working-with-your-remote-repository-on-github-or-github-enterprise/syncing-your-branch-in-github-desktop).
